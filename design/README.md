# Diseño y guía de referencia visual

## Qué es Stitch

Stitch es una herramienta de diseño y prototipado que puede exportar pantallas en HTML, imágenes y otros recursos. En este repositorio, las carpetas exportadas desde Stitch son una referencia visual del diseño y no forman parte del código fuente de la aplicación.

## Qué contiene la exportación

La carpeta `design/stitch-export/` contiene todas las pantallas exportadas desde Stitch, incluyendo HTML, imágenes y activos visuales. Estas carpetas reflejan la estructura y presentación del diseño, pero no son componentes React ni código ejecutable del producto.

## Cómo usar estas pantallas como referencia

- Revisa los diseños para entender la estructura visual, el copy y la jerarquía de información.
- Usa los assets como guía para componer layouts, componentes y estados en la aplicación.
- Utiliza las pantallas para validar que el diseño final coincide con la experiencia esperada.

## Qué no debe hacerse con estos archivos

- No convertir automáticamente HTML en React.
- No importar estas carpetas ni archivos HTML en la aplicación.
- No usar estos archivos como código fuente o lógica.
- No renombrar, editar ni reescribir los HTML exportados.
- No reposicionar estos archivos fuera de `design/stitch-export/`.
