# Imagenes de Warmi Digital

Reemplaza estos archivos manteniendo el mismo nombre para actualizar la web sin tocar codigo:

- `brand/warmi-logo.png`: logo principal de Warmi Digital.
- `auth/artesana.png`: imagen para la tarjeta e ingreso de artesanas.
- `auth/facilitadora.png`: imagen para la tarjeta e ingreso de facilitadoras.

Puedes usar `.png`, `.jpg` o `.webp`, pero si cambias la extension tambien debes actualizar las rutas en el codigo.
